# ZAPE Sport Wear — site

Site da ZAPE Sport Wear (zapesportwear.com.br): camisas de time personalizadas, sob encomenda.

## Páginas
- `index.html` — site: arara interativa, estúdio de design 2D, modelos, orçamento via WhatsApp
- `pedido.html` — protótipo do link de acompanhamento do pedido + painel admin + pagamento (dados de demonstração no navegador)

## Pendências
- Número real do WhatsApp (`const WHATSAPP` em `index.html`)
- @ do Instagram e horário de atendimento
- Banco de dados (Supabase) e gateway de pagamento para o link do pedido
- Drops mensais de estampas no estúdio + admin

## Publicar
Site estático: funciona direto no Netlify ou Cloudflare Pages, sem build.
